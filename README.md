# 3D's Royal Clothing — VS Code project

## Open the website
1. Extract this folder if you downloaded the ZIP.
2. Open Visual Studio Code.
3. Choose **File → Open Folder** and select `3ds-royal-clothing-vscode`.
4. Open `index.html`.
5. Run it with the **Live Server** extension (right-click `index.html` → **Open with Live Server**), or open `index.html` directly in your browser.

## Project files
- `index.html` — page structure and content
- `style.css` — responsive design and styling
- `script.js` — navigation, catalogue, wishlist, shopping bag, search, and contact form validation/demo feedback

## Notes
- Product images load from Unsplash, so an internet connection is needed for those images.
- The contact form currently validates in the browser and shows demo feedback. It does not send or store messages.
- Product data and prices are sample content.
- No backend or payment processing is included.
